## 🌟 Modern Executive Glassmorphic Architecture

This project is the complete, high-performance web application version of the **Metropolitan Management Intelligence Dashboard**, crafted into a sleek, ultra-modern SaaS executive cockpit (inspired by Linear, Stripe, Apple, and Vercel design systems):

1. **Executive Visual Identity & Canvas Design**:
   - **Default Light Theme**: Crisp, luminous `#F8FAFC` canvas with subtle ambient mesh glow orbs.
   - **Translucent Glass Cards**: Frosted `rgba(255, 255, 255, 0.88)` card surfaces with `backdrop-filter: blur(16px)`, soft `14px` rounded corners, and luminous 1px borders.
   - **Refined Typography**: Modern executive font stack featuring **Outfit** and **Plus Jakarta Sans** with clean letter-spacing and high-contrast callout metrics.
   - **Metropolitan Corporate Gradient Highlights**: Elegant top accents featuring Metropolitan Deep Blue (`#003882`), Electric Cyan (`#00B4D8`), Emerald Success (`#107C41`), and Royal Amethyst (`#744DA9`).

2. **Ultra-Modern Executive Glass Header**:
   - Metropolitan Corporate emblem + glowing live telemetry beacon (`LIVE DATA`).
   - Breadcrumb navigation with active page title highlight.
   - High-contrast digital synchronization clock capsule.
   - Action controls with spring micro-interactions: Manual Sync (`F5`), 10-Slide Matrix (`G`), Audio Haptics (`M`), Dark/Light Mode Toggle (`T`), Fullscreen Kiosk Mode (`F`), Diagnostics (`D`), Admin Settings (`A`), Shortcuts Legend (`?`), and About Developer.

3. **Modern Segmented Pill Slicers**:
   - **Period Slicer**: `MTD November 2026`, `Q3 FY 2026/27`, `YTD Full Year`.
   - **Division Slicer**: `All Metropolitan Divisions`, `CSBM Business Division`, `Copier Engineering`, `Toner & Consumables`.
   - **Region Slicer**: `Islandwide Sri Lanka`, `Western Province / Colombo`, `Central Province / Kandy`, `Southern Province / Galle`.
   - Real-time worksheet connection beacon (`14 Worksheets Connected`) and 60-second auto-cycle indicator.

4. **Executive Live Telemetry Ticker Marquee**:
   - 100% verified commercial operations feed (CSBM Run-Rate, Top Champion Chamara Sampath, AMC Contracts Pipeline, Consumables Toner Revenue, Debt Recovery, and Provincial Market Share).
   - All legacy field service / FSMS job mentions completely eliminated.

5. **Ultra-Modern Executive Floating Dock Navigation**:
   - Frosted glass floating pill dock at the bottom of the cockpit.
   - Smooth 60-second slide advance progress track (`#slideProgressFill`) with Metropolitan blue-cyan gradient fill.
   - Media controls: Previous (`◀`), Play / Pause (`⏸`), Next (`▶`).
   - Segmented page pills with active gradient fill, numeric badges, and smooth scroll into view.
   - Sub-panel navigation dots with spring scale and `PAUSED` status badge.

6. **100% Google Sheets Commercial Data (Zero FSMS / Zero Login Friction)**:
   - Anyone visiting the site instantly sees verified telemetry data with **no login prompts, no popups, and no credentials required**.
   - All FSMS breakdown/field jobs have been completely removed and replaced with verified Google Sheets commercial intelligence (AMC Renewal Pipeline, Field Estimates, Daily Invoicing Run-Rate).

## 🚀 How to Run the Website

### Method 1: Instant Direct Launch (No Web Server Required)
Simply open:
```
D:\dashboard website 13.11.2026\index.html
```
Double-click `index.html` in Windows Explorer or open it in Google Chrome, Microsoft Edge, Safari, or any smart TV browser.

### Method 2: Local HTTP Server (Optional)
Open PowerShell in `D:\dashboard website 13.11.2026`:
```powershell
cd "D:\dashboard website 13.11.2026"
python -m http.server 3000
# OR
npm start
```
Then visit `http://localhost:3000` in your web browser.
